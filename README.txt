THIỆP MỜI TỐT NGHIỆP — TRẦN PHẠM THANH PHONG

CÁCH MỞ:
1. Giải nén thư mục.
2. Mở file index.html bằng Chrome, Edge hoặc trình duyệt trên điện thoại.

CÁCH CHỈNH NGÀY / GIỜ / ĐỊA ĐIỂM / LIÊN HỆ:
Mở index.html bằng VS Code hoặc Notepad.
Tìm đoạn const INVITATION = { ở gần cuối file.
Sửa các trường:
- date: ngày tổ chức
- time: giờ tổ chức
- venue: tên địa điểm
- address: địa chỉ
- mapUrl: link Google Maps
- contact: tel:09xxxxxxxx hoặc mailto:email

Website hiện dùng nội dung “Sẽ cập nhật” cho thời gian và địa điểm vì bạn chưa cung cấp thông tin này.
Google Fonts cần Internet để tải font Playfair Display và DM Sans; nếu offline trang vẫn hoạt động với font thay thế.
